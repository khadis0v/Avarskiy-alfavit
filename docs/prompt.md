# Задание на предварительный просмотр

Эстетика: тёмный учебный интерфейс; крупные читаемые буквы; спокойные поверхности; одна группа из 13 кнопок; явные состояния выбора и фокуса; без декоративных изображений.

Референс: предыдущая беседа с перечнем 13 особых букв. Сохранить буквы и алфавитный порядок, не переносить приблизительные фонетические объяснения в интерфейс.

Интент: пользователь сразу видит буквы и нажимает нужную. На предварительном просмотре пользователь переключает пять разных тёмных оформлений мышкой.

Рамки: один HTML без внешних зависимостей; телефон и компьютер; никаких выдуманных записей или русского синтеза вместо аварского. Отдельные звуки без слов, один диктор — требование полной версии, пока не выполнено. Четыре подлинные записи встроены для проверки прототипа. Неполнота явно показана пользователю. Фото, маркетинговые секции, аналитика, публикация и поисковое продвижение не требуются.

Варианты: сине-серая клавиатура; графитовые круги; зелёная плотная сетка; синие прямоугольные клавиши; коричнево-серые контурные клавиши. Все остаются в подтверждённой тёмной теме. Шрифты содержат кириллицу и встроены в HTML.
