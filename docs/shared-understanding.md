# Подтверждено пользователем 2026-11-24

## Последующие уточнения, заменяющие исходное требование к отдельным звукам

Пользователь выбрал оформление 1 со скриншотом, разрешил слоги и попросил после слога воспроизводить три простых аварских слова. Реализовано в avarsky-alfavit.html и index.html: 13 последовательностей из записей пособия СПбГУ, более длинный слог нарезан из начала первого слова, затем пауза 320 мс и три слова подряд, на экране показаны переводы. Фонетические границы нарезки не проверены носителем; совпадение диктора гарантируется между слогом и первым словом, поскольку это одна исходная запись. Требование одного диктора для всех записей не верифицировано по источнику.

Ниже сохранено исходное согласование как история; актуальный результат описан выше и в docs/decisions.md.

13 кнопок: Гъ, Гь, ГӀ, Къ, Кь, КӀ, Лъ, ТӀ, Хъ, Хь, ХӀ, ЦӀ, ЧӀ.
Отдельные звуки без слов, один диктор. Повтор с начала, одна запись одновременно.
Тёмная тема, крупные буквы без пояснений. Телефон и компьютер.
Один автономный HTML-файл без внешних зависимостей.

## Ограничение, выявленное после интервью
В учебном пособии найдены записи слов для всех выбранных букв; полный набор в видео произносится слогами.
Нельзя выдавать слоги за отдельные звуки или утверждать одного диктора без проверки.
Допустимость слогов подтверждена пользователем.
