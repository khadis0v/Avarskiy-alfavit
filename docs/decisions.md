# Решения

2026-11-24: выбран вариант 1: пользователь указал номер и приложил скриншот. Сине-серая палитра, Golos Text, крупные прямоугольные клавиши, сетка 7 столбцов на компьютере и 3 на телефоне.

2026-11-24: пользователь разрешил слоги вместо отдельных звуков, затем уточнил последовательность «слог, короткая пауза, затем три простых аварских слова подряд».

Озвучка: записи слов учебного пособия СПбГУ, слог нарезан из отдельного исходного слова, пауза 320 мс, затем три записи без добавленных пауз. Для 7 букв первое слово переставлено так, чтобы оно не начиналось с изучаемой буквы: буква находится внутри или в конце слова. Для ХӀ добавлено слово «хӏелеко» («петух»); его читает системный голос браузера, поскольку подходящей исходной записи не найдено. Единый диктор всех исходных записей в источнике не указан. Границы слогов не проверены носителем. Не заявлять профессиональную фонетическую верификацию.

Одна страница с буквами и выбранным словом: дополнительных секций нет. Раскладка основного экрана закреплена выбором пользователя со скриншотом; второй выбор тела не добавляет самостоятельного содержания.

Результат — один локальный HTML, без аналитики и внешних загрузок. Требования к фотографиям, robots.txt, sitemap и социальной карточке неприменимы.

Варианты сохранены в variants.html и variants/. В конечном HTML переключателей оформления нет.
