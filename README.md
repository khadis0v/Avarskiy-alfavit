# Аварский алфавит

Статическая PWA-страница для тренировки 13 особых букв аварского алфавита. Нажатие на букву проигрывает три встроенных слова; интернет для воспроизведения не нужен.

## Локальный запуск

Откройте `index.html` или `avarsky-alfavit.html`. Для установки как приложения используйте HTTPS-размещение.

## Установка на рабочий стол

После размещения по HTTPS в Chrome/Edge нажмите значок установки в адресной строке или выберите «Установить приложение». На iPhone/iPad: «Поделиться» → «На экран Домой».

## Публикация

Содержимое этой папки — готовый статический сайт. На сервере достаточно отдать её как корень сайта по HTTPS. Файл `sw.js` обеспечивает офлайн-открытие после первого посещения.
