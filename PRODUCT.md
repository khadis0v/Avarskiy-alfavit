# Продукт

- Дело и для кого: личное изучение 13 особых букв аварского алфавита.
- Целевое действие: нажать крупную букву и услышать три простых аварских слова подряд.
- Тон: краткий русский интерфейс, без фонетических пояснений у букв.
- Настоящие материалы: записи слов из https://pkholyavin.github.io/avar/. Полный набор одного диктора в https://www.youtube.com/watch?v=Klo83A0OBro состоит из слогов и не используется.
- Подтверждено 2026-11-24: тёмная тема, телефон и компьютер, один локальный HTML со встроенным звуком, без интернета; один диктор. Одновременно играет одна запись; повторное нажатие запускает заново.
- Уточнение 2026-11-24: пользователь выбрал оформление 1 и попросил три простых аварских слова без слогов.
- Текущая версия: 13 последовательностей из трёх слов подряд, с переводом всех трёх слов. Внутри каждого набора соседние слова начинаются с разных букв. Все слова используют встроенные записи.
- Для ЧӀ используются «мачӏу» («кремень»), «бачӏин» («приезд») и «чӏор» («стрела»): ни одно из соседних слов не начинается с той же буквы.
